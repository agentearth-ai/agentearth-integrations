# AgentEarth for Hermes

The [AgentEarth plugin](plugin/) bundles 31 English-language skills and connects Hermes to the hosted AgentEarth MCP server.

See the [plugin README](plugin/README.md) for installation, browser OAuth setup, example requests, and how data and credits are handled.

## Validate the package

From the repository root, run:

```bash
hermes plugins validate hermes/plugin --install-deps
```
